# 羅針占術 SNS運用方針 2026-05

作成日: 2026-05-12

この文書は、羅針占術のThreads/X運用、無料体験導線、深掘り鑑定への案内、Codex自動投稿の安全ルールをまとめたものです。

## 結論

2026年5月16日からの2週間は、売る期間ではなく、無料体験から有料興味までの導線を検証する期間にする。

主導線は次の順番に固定する。

1. SNS投稿
2. 今日のオラクル
3. 無料鑑定
4. 鑑定結果画面
5. 深掘り鑑定案内
6. BOOTH購入
7. 注文番号入力
8. 深掘り鑑定

SNSでは有料を強く売らない。SNSの役割は、毎日触れる無料入口と信頼形成。購入判断はアプリ内の結果画面で行う。

## 投稿構造

### 07:00 JST: 今日の数秘オラクル

目的は、毎朝の無料接点を作ること。

要件:

- 数秘オラクルカードを1枚ランダム選択する。
- 対応するカード画像を添付する。
- alt textを付ける。
- 投稿文はThreadsの500文字以内に収める。
- ハッシュタグは原則 `#羅針占術` のみ。
- 締めは `あなたも今日の1枚を引かない？` にする。
- UTMは `utm_content=oracle_YYYYMMDD`。

テンプレート:

```text
【今日の数秘オラクル】

今日の1枚：{{cardName}}
テーマ：{{theme}}

今日は、{{shortMessage}}

迷っていることがあるなら、
まずは「今すぐ決めること」と
「もう少し見てもいいこと」を分けてみてください。

カードからのメッセージ：
{{message}}

今日の一手：
{{action}}

{{shareUrl}}

#羅針占術

あなたも今日の1枚を引かない？
```

### 20:00 JST: 思想・信頼形成投稿

目的は、羅針占術の考え方を積み上げること。

主なテーマ:

- 羅針占術とは何か
- 今日のオラクルの使い方
- 無料鑑定で見えるもの
- 鑑定結果を記録する価値
- 当てるより整理する占い
- 恋愛で相手の気持ちを断定しない理由
- 仕事やお金の迷いの整理
- 専門判断の代替にしない注意
- 深掘り鑑定の使いどころ
- BOOTH購入後の流れ

20時投稿は、売るよりも「この占いは不安を煽らない」「判断材料を整理する」という信頼を作る。

### X投稿

XはThreadsと完全同文にしない。

Xでは、短いフック、検索される言葉、引用されやすい言い切りを優先する。ただし断定・不安煽りは禁止。

例:

```text
迷っているときは、
「答えがない」のではなく、
問いが大きすぎることがあります。

今すぐ決めること。
もう少し見てもいいこと。
人に相談したほうがいいこと。

まずは3つに分けるだけで、
次の一手は見えやすくなります。

#羅針占術
```

Codex投稿生成では、X用に `xText` を別生成する。UTMは `utm_source=x` にする。

## 有料導線ルール

SNSでは弱く、アプリ内では明確にする。

### SNSで使ってよい表現

- 無料鑑定で見えた流れを、もう少し深く整理したい方向けに、深掘り鑑定も用意しています。
- 必要な方だけ、無料鑑定のあとに深掘り鑑定へ進める形です。
- 深掘り鑑定は、無料鑑定で見えた流れを追加カードと追加質問で具体化する鑑定です。

### SNSで避ける表現

- 今すぐ購入してください。
- 深掘りしないと本当の答えはわかりません。
- 有料でないと悪い流れを変えられません。
- 今日だけこの価格です。
- Stripeで今すぐ購入できます。

Stripe Checkoutは無効。SNSでもアプリでもStripe前提の購入CTAは出さない。

### アプリ内で強くする場所

1. 今日のオラクル後: 無料鑑定への案内
2. 無料鑑定結果後: 深掘り鑑定への案内
3. 鑑定履歴画面: 前回からの変化を深掘りする案内

結果画面の主文脈は「この相談を、もう少し深く整理しますか？」にする。購入ではなく、整理・追加質問・次の一手を価値として見せる。

## BOOTH導線

BOOTH関連の購入情報はSNS上では扱わない。公開投稿、リプライ、DMで注文番号を求めない。

アプリ内では次の順番にする。

1. 深掘り鑑定の内容を説明する。
2. `BOOTHで購入する` を押す。
3. BOOTHで購入する。
4. アプリに戻り、注文番号を入力する。
5. 注文番号を確認する。
6. 深掘り鑑定を開始する。

注文番号案内:

```text
注文番号は、BOOTHの注文内容確認メール、または購入履歴から確認できます。
公開投稿やリプライには書かず、この画面に入力してください。
```

## 安全表現ルール

投稿前に次を確認する。

- 未来を断定していないか。
- 相手の気持ちを決めつけていないか。
- 不安を煽って課金につなげていないか。
- 医療・法律・投資など専門判断の代替に見えないか。
- 最後が小さな行動に落ちているか。

NG表現:

- 絶対当たる
- 100%当たる
- 必ず当たる
- 運命の人
- 復縁できます
- 必ず戻ってくる
- 課金しないと
- 買わないと悪くなる
- このままだと不幸
- 手遅れ
- 病気が治る
- 投資で勝てる
- 法律的に大丈夫
- 今すぐ購入しないと

OK表現:

- 今の状況を整理するヒント
- 関係性を見直すきっかけ
- 距離感と自分の本音を整理する
- 必要な方だけ深く整理できます
- 今見直せることがあります
- 専門判断は医療機関や専門家へ
- 投資判断の代替には使わない

## Codex自動投稿設定

基本設定:

```env
PUBLIC_ORIGIN=https://rashin-senjutsu.onrender.com
SOCIAL_AUTOMATED_POSTING_ENABLED=true
SOCIAL_PLATFORMS=threads
SOCIAL_ORACLE_TIME=07:00
SOCIAL_CONCEPT_TIME=20:00
SOCIAL_UTM_CAMPAIGN=202605_prerelease
SOCIAL_PAID_CTA_MODE=soft
SOCIAL_RELEASE_MODE=prelaunch
SOCIAL_BOOTH_ENABLED=false
```

`SOCIAL_PAID_CTA_MODE`:

| 値 | 意味 |
| --- | --- |
| off | 有料導線を出さない |
| soft | 深掘り鑑定を説明するが、購入訴求は弱める |
| active | BOOTH購入導線を明確に出す |

初期値は `soft`。BOOTH商品ページ、注文番号入力、注文番号確認フローが本番確認できるまで `active` にしない。

`active` を使う条件:

- `SOCIAL_PAID_CTA_MODE=active`
- `SOCIAL_BOOTH_ENABLED=true`
- `BOOTH_DEEP_READING_URL` または `BOOTH_PRODUCT_URL` が設定済み
- 本番で注文番号確認フローを検証済み

## KPI

最初の2週間は購入数だけを見ない。見る順番は次の通り。

1. 今日のオラクル投稿の表示数・反応
2. アプリへのクリック数
3. 今日のオラクル利用数
4. 無料鑑定開始数
5. 無料鑑定完了数
6. 深掘り鑑定CTA表示数
7. 深掘り鑑定CTAクリック数
8. BOOTH購入ページクリック数
9. 注文番号入力開始数
10. 注文番号確認成功/失敗
11. 深掘り鑑定完了数

判断軸は「SNSから無料体験に入るか」「無料鑑定を完了できるか」「結果画面で深掘り興味が出るか」。最初から売上だけで評価しない。

## 採用しない方針

- 初期から月額サブスクを売る。
- 回数券、高額鑑定、限定鑑定を増やす。
- 恋愛不安を煽る商品に寄せる。
- 金運改善や投資判断を売りにする。
- DM個別占いへ誘導する。
- 自動リプライ占いを始める。
- XをThreadsと同文で自動クロスポストする。

初期商品は単発の深掘り羅針鑑定に集中する。
