# 羅針占術 有料鑑定 追加質問改善 共有資料

作成日: 2026-05-15
対象リポジトリ: `C:\Users\tf547\uranai`
対象変更: 追加質問の動的化 + プレリリース前の鑑定生成ブリーフ強化
共有範囲: ソースコード全文、実ユーザー本文、回答データ、環境変数、羅針コード在庫は含めない

## 1. この資料の目的

この資料は、データを共有できない別の ChatGPT に、有料鑑定の「追加質問」がどのように改善されたかを説明するためのものです。

共有するのは、実装の考え方、変更点、期待される挙動、検証観点、レビュー依頼用プロンプトだけです。

## 2. 変更前の状態

有料鑑定の追加質問は、ほぼ固定テンプレートに寄っていました。

出やすかった質問の方向:

- いちばん白黒をつけたいこと
- 頭では分かっているのに動けない理由
- 進む条件と止まる条件
- 行動準備度
- 持ち帰りたい判断軸

この方式では、相談本文、カード状況、人物カード、障害カード、曖昧カード、未来カード、オラクルカード、動物タイプ診断の違いが質問に十分反映されませんでした。

結果として、ユーザーが「これは自分のための質問だ」と感じにくく、追加質問がカード解釈の精度を上げる役割を果たしきれていませんでした。

## 3. 変更後の状態

追加質問は、固定5問ではなく、相談内容とカード状況に応じて候補を作り、その中から3〜5問を選ぶ方式になりました。

見る材料:

- 相談カテゴリ
- 相談本文
- `baseFocus`
- `refinedFocus`
- ルノルマンカード9枚
- `coreCard`
- `futureCard`
- `blockerCard`
- `ambiguityCard`
- `externalCard`
- `peopleCard`
- `currentOrc`
- `futureOrc`
- 動物タイプ診断
- 選択済み相談タグ

生成する質問候補:

- 主テーマ確認
- 曖昧カード確認
- 障害カード確認
- 人物カード確認
- 好転カード確認
- オラクル行動確認
- 進む/止まる/保留の判断条件確認

選別ルール:

- 相談文で既に答えている質問は落とす
- カード重要度が高い質問を優先する
- `refinedFocus` で不足している情報を優先する
- 同じ意味の質問を重複させない
- 相談文の長さや複雑さに応じて3〜5問に調整する

## 4. 実装上の主要ポイント

実装ファイル:

`C:\Users\tf547\uranai\app.js`

主な関数:

- `renderClarifyScreen()`
  - 質問番号、質問ラベル、質問本文、短い手がかりを表示する。
- `buildClarifyPromptText()`
  - 回答本文だけでなく「何を聞いた質問への回答か」も最終鑑定側へ渡す。
- `buildClarifyContext()`
  - 相談カテゴリ、本文、カード、オラクル、動物タイプ診断などを一つの文脈にまとめる。
- `buildClarifyQuestionCandidates()`
  - カード状況と相談テーマに応じた質問候補を作る。
- `rankClarifyQuestions()`
  - 候補を重複排除し、3〜5問へ絞る。
- `buildPremiumReadingFocusBrief()`
  - 主テーマ、相談者が欲しい答え、カード根拠、追加質問回答、動物タイプ診断、断定レベルを1つの鑑定ブリーフに圧縮する。
  - 全カードデータを本文へ詰め込まず、主軸・近い未来・障害・未確認・人物・好転・オラクル行動を優先する。
- `detectPersonalizationCoverageIssues()`
  - 相談本文や追加質問回答の具体語が鑑定本文に反映されているかを品質チェックに追加する。

## 4.1 プレリリース前に追加した生成品質の強化

追加質問だけではなく、実際の有料鑑定本文の満足感を上げるために、生成前に `buildPremiumReadingFocusBrief()` で「今回の鑑定で何を優先して読むか」を明示するようにしました。

鑑定ブリーフに含めるもの:

- 主テーマ
- 相談者が欲しい答え
- 冒頭2文で答えるべき方向
- 相談本文から拾う具体語
- 動物タイプ診断の使い方
- ルノルマンの主軸、近い未来、障害、未確認、人物、好転カード
- オラクルの現在/未来カードが示す行動方向
- 追加質問回答の要約
- データ圧縮ルール
- 断定レベル

狙い:

- 読み込むデータが多すぎてAIが散らかる問題を抑える。
- 相談者本文の言葉を鑑定文へ自然に反映する。
- カード名や配置説明ではなく、現実の判断条件へ翻訳する。
- 安全上、他人の心や未来の無根拠な断定は避けつつ、進む/止まる/保留の判断条件は強く言い切る。
- 保存カードや統合判断まで、追加質問の回答を条件分岐へ反映させる。

## 5. UIの変更

質問ごとに以下を表示します。

- 質問番号
- 何を確認する質問かの短いラベル
- 質問本文
- 任意の短い手がかり

例:

ラベル: `未確認の本音`
質問: `「復縁」について、まだ相手に確認できていないことがあるなら、それは何ですか？`
手がかり: `曖昧さを示すカードが出ているため、ここを言葉にすると最終判断が強くなります。`

## 6. 期待される挙動

恋愛復縁ケース:

- 復縁、未確認事項、過去の原因、相手の反応に寄った質問になる。
- 例: 相手に確認できていないこと、連絡や会う姿勢、過去の原因への向き合い方。

仕事継続ケース:

- 残る条件、動く条件、収入、評価、成長、消耗度に寄った質問になる。
- 例: 今の仕事で一番はっきりしていないこと、残る価値、別の動きへ進む条件。

曖昧カードが出た場合:

- 雲、本、月、蛇、キツネなどに応じて、未確認事項や信用しきれない点を聞く。

障害カードが出た場合:

- 山、十字架、棺、鎌、ネズミ、鞭などに応じて、現実の壁や負担を聞く。

好転カードが出た場合:

- 太陽、星、鍵、花束、クローバー、騎士などに応じて、何を確認できれば進めるかを聞く。

人物カードが出た場合:

- 紳士、淑女、熊、百合、犬、蛇、キツネなどに応じて、誰の態度や距離感を見るかを絞る。

オラクルカードが行動方向を示す場合:

- 動く、整える、待つ、選ぶ、変えるなどの方向を、今週の一手に近い質問へ落とす。

## 9. 共有しないもの

## 10. 一言説明

今回の改善は、追加質問を「毎回同じ確認」から「相談本文とカード配置を使って、最終判断の解像度を上げる確認」に変えるものです。
