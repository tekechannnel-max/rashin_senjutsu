# 羅針占術リーディング設計メモ

## 分離した取扱説明書

- `rashin-reading-policy.js`
  - 無料鑑定と有料鑑定の境界
  - 羅針コード・BOOTH購入確認と鑑定本文を混ぜない運用
  - タグ選択の扱い
  - ルノルマン、数秘オラクル、統合判断の役割
  - 文章生成の注意点
  - 表示禁止語と品質検査の観点

## カード解釈データ

- `lenormand-reading-knowledge.js`
  - ルノルマンの深掘り読解補助
  - 復縁など、テーマ別のカード解釈補助
  - 本文へ出してはいけない内部配置語

- `oracle-reading-knowledge.js`
  - 数秘オラクルのテーマ別補助
  - 復縁など、内面整理向けの置換・補足

- `card-reading-knowledge.js`
  - タグ、判断軸、追加質問、羅針カード生成に使う相談テーマ別の知識

## 本体側に残すもの

- `app.js`
  - 画面操作
  - 鑑定フロー
  - カード抽選
  - プロンプト組み立て
  - 品質ゲート
  - fallback生成

## 運用ルール

- 鑑定の考え方や禁止表現を増やす場合は、まず `rashin-reading-policy.js` を更新する。
- カード固有の解釈を増やす場合は、対応する knowledge ファイルへ追加する。
- `app.js` へ直書きするのは、状態管理や画面表示など実装上必要な処理に限る。
- 無料鑑定は、無料2枚/1枚で言える範囲に抑える。
- 有料鑑定は、追加カード・追加質問・履歴を使う深掘りとして分ける。
