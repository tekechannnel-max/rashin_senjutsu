# SNS投稿 絶対ルール

作成日: 2026-06-05
最終改定日: 2026-06-07
対象: 羅針占術のThreads / Instagram投稿、投稿文生成、画像生成、予約投稿、自動投稿設定、削除、再投稿

このファイルは、SNS投稿作業で最初に読む強制ルールです。`docs/sns-runbook.md` やスクリプトが存在していても、このファイルに反する解釈、補完、投稿、削除、再投稿をしてはいけません。

## 最重要原則

AIはユーザーの最新指示を勝手に解釈しない。

素材フォルダ、投稿文、投稿日時、投稿枚数、媒体のどれかが未確定なら、作業を止めて質問する。推測で補完して投稿しない。

## 正本の優先順位

1. ユーザーの最新指示
2. ユーザーが明示的に確定した本文、画像、日時、媒体
3. このファイル
4. `docs/sns-runbook.md`
5. 現在のスクリプトのdry-run結果

古いJSON、古いdocs、古いチャット要約、過去の投稿事故時の暫定ルールで上位の情報を上書きしてはいけない。

## 現在の投稿ルール

### 毎日 8:00

朝の投稿は、次のフォルダだけを使う。他は絶対に触らない。

```text
D:\株式会社 天仙\羅針占術\images\social\instagram\oracle
```

### 毎日 20:00 / 21:00 / 22:00 / 23:00

夜の通常投稿は、カルーセル投稿または普通の画像投稿として、次のフォルダだけを使う。他は絶対に触らない。

```text
D:\株式会社 天仙\羅針占術\images\social\instagram\【インスタ】あるある・ランキング系
```

投稿する画像、順番、本文が確定していない場合は投稿しない。

### 木曜日 20:00

木曜日の20:00枠は、夜の通常投稿より優先して、次の3枚だけでカルーセル投稿する。他は絶対に触らない。

```text
D:\株式会社 天仙\羅針占術\images\social\instagram\difference.jpg
D:\株式会社 天仙\羅針占術\images\social\instagram\free-paid-compare.jpg
D:\株式会社 天仙\羅針占術\images\social\instagram\rashin_point.jpg
```

### 毎月1日 20:00 / 21:00 / 22:00 / 23:00

毎月1日は絶対優先で、次のフォルダだけを使う。他は絶対に触らない。

```text
D:\株式会社 天仙\羅針占術\images\social\instagram\誕生日数×ルノルマン
```

このフォルダ配下のサブフォルダと画像は使用してよい。`2026-06\25-31` のような月別・範囲別フォルダも、この指定フォルダ内なので使用可能とする。

毎月1日の20:00 / 21:00 / 22:00 / 23:00には、夜の通常投稿と木曜日20:00投稿を入れない。

### 誕生日系Instagramのハッシュタグ

誕生日系Instagram投稿には、確定済みの方針として次を必ず入れる。

```text
#誕生日占い
#数秘
```

## 投稿前承認ゲート

外部投稿、削除、再投稿、予約変更、自動投稿設定変更の前に、必ず次をそのまま提示する。

- 投稿日時
- platform
- 投稿種別
- 画像パス
- 画像枚数
- 投稿本文
- ハッシュタグ
- 既知の制限、未確認点、リスク

ユーザーが明確に承認するまで投稿しない。曖昧な返事を承認扱いしない。

## 絶対停止条件

次のどれかに当たる場合は、作業を止めて質問する。推測、分割、代替画像生成、文面変更で回避しない。

- 投稿文が未確定。
- 画像が未確定。
- フォルダ内のどの素材を使うか未確定。
- 画像の順番が未確定。
- 画像枚数がplatform上限にぶつかる。
- ThreadsとInstagramで同一内容か別文か不明。
- 同じ時刻に複数投稿が衝突する。
- 指定フォルダ外の素材を使いそうな場合。
- 既存画像があるのに新規生成しようとしている。
- 外部投稿済みの削除、再投稿、上書きが必要になりそうな場合。

## 禁止

- 勝手に投稿文を作らない。
- 勝手に投稿文を言い換えない。
- 勝手にハッシュタグを抜かない。
- 勝手に画像を新規生成しない。
- 勝手に指定フォルダ外の素材を使わない。
- 勝手に別日へ移動しない。
- 勝手に分割投稿しない。
- 古いJSONの本文を正本扱いしない。
- local dry-runだけで自動投稿完了と言わない。
- 投稿URL未確認のまま投稿成功と言わない。

## 自動投稿の完了条件

「自動投稿できる」と報告できるのは、次を確認した後だけ。

- PCやCodexが起動していなくても動くクラウド実行経路がある。
- Render CronまたはGitHub Actionsの実行時刻がJST投稿時刻に合っている。
- Threads / Instagramの認証情報がクラウド側に設定されている。
- dry-runで対象投稿が正しい時刻にdueになる。
- 実投稿、または実投稿相当の検証で本文、画像、URL、重複有無を確認できる。
- 失敗時に検知できるログ、通知、または監査手順がある。

どれか未確認なら、未確認と明記する。120点と断言しない。
