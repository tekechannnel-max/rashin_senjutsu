# SNS固定投稿コピー

このメモは、Threads / X のプロフィール固定投稿を見直すときの再利用用。投稿操作はここでは扱わない。本文案を作り、人間がSNS画面で確認して固定する。

## 作業ルール

- 最新のSNS傾向は毎回確認する。X / Threads の仕様や推奨は変わるので、古い記憶だけで「最適」と言わない。
- Xは自動投稿しない。固定投稿の本文案を作るだけにする。
- Threadsも、固定投稿の差し替えや固定操作は人間が行う。Codexは本文案と理由を出す。
- URL、提供機能、有料導線、毎朝投稿時刻が現在のアプリ実態と合っているか確認してから出す。
- 広告文だけにせず、「誰の何を整理するアプリか」を最初に伝える。
- ハッシュタグを増やさない。固定投稿では原則なしでよい。

## 見直し観点

- 1行目で投稿者とアプリ名が分かる。
- 2ブロック目で価値が分かる: 迷い、悩み、今の自分、次の一手。
- 無料機能は長い箇条書きより、1行にまとめてスキャンしやすくする。
- 有料は「無料結果をそのまま深掘りできる」と説明し、売り込みを強くしすぎない。
- CTAは1つにする: 無料で今日の1枚を引く。
- Threads固定投稿は500文字以内を目安にする。Xにも流用する場合は、280文字制限や長文投稿可否を別途確認する。

## 現行推奨案 2026-05-24

調査反映:

- X公式のOrganic Post copy方針に合わせ、簡潔・会話調・CTAは1つにする。
- Threads向けには、長い宣伝より「何の迷いをどう整理するか」を先に出し、返信や会話につながりやすい自然な文にする。
- 現在の実装では無料結果画面から羅針カード発行ボタンは表示されないため、羅針カードは深掘り鑑定側の機能として書く。
- 朝の数秘オラクルは運用設定上 `08:00 JST`。

```text
仙斎 天氣（せんさい てけ）です。
AI占いWEBアプリ『羅針占術』を作りました🧭

占い結果を眺めるだけでなく、
「自分は何に迷っているのか」
「次にどこを見ればいいのか」
まで言葉にするための占いアプリです。

無料でできること：
姓名判断／四柱推命／動物タイプ診断／ルノルマン2枚／数秘オラクル1枚／SNSシェア

深掘り鑑定では、無料結果の続きから
ルノルマン9枚・数秘オラクル3枚・羅針カードまで展開します。

毎朝8:00に「今日の数秘オラクル」も投稿中。
まずは無料で今日の1枚を引いてみてください。
https://rashin-senjutsu.onrender.com
```

## Instagramプロフィール案

Instagramでは投稿キャプション内URLを主導線にしない。プロフィールリンクを前提に、何を整理できるアプリかを短く伝える。

```text
AI占いWEBアプリ『羅針占術』
迷いを、本音・現実・次の一手に整理
毎朝8:00 今日の数秘オラクル
無料鑑定はプロフィールリンクから
```

## Instagram固定投稿・ハイライト案

- 固定1: 「羅針占術とは」 - 未来を断定する占いではなく、迷いを判断軸に戻すアプリだと説明する
- 固定2: 「無料でできること」 - 姓名判断、四柱推命、動物タイプ診断、ルノルマン2枚、数秘オラクル1枚
- 固定3: 「深掘り鑑定」 - 必要な人だけ、無料結果の続きからルノルマン9枚と数秘オラクル3枚へ進む
- ハイライト: 「使い方」「今日の1枚」「無料鑑定」「深掘り」
