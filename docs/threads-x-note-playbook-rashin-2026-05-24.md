## 無料公開部分

Threadsで占いアプリを売るときに、最初に捨てるべき考え方があります。

それは「毎日URLを貼れば売れる」という考え方です。

占いアプリ、とくに羅針占術のように「迷いを整理し、次の一手を言葉にする」タイプのサービスは、いきなり販売ページへ飛ばすよりも、先に読者の中で次の感覚を作る必要があります。

- この人の言葉は、自分の悩みに近い
- 無料で1回試してもよさそう
- 結果をもう少し深く読みたい
- 毎日見ても疲れない
- 占いなのに、押し売りではなく整理してくれる

この資料では、Xでよく機能する投稿設計をベースに、Threads向けに変換した運用方法をまとめます。

X公式のオーガニック投稿方針では、投稿文は簡潔にし、ハッシュタグを乱用せず、必要なときだけ明確なCTAを置き、会話調にすることが推奨されています。Threads公式側では、返信が表示拡大に強く関わり、会話を生む投稿が推奨されやすいと示されています。

つまり、羅針占術のThreads運用はこう考えます。

> 売り込む前に、読者の迷いを1つ言語化する。
> 占う前に、読者が「今の自分のことかも」と思える入口を作る。
> 有料導線は、無料体験のあとに自然に置く。

この資料は、ただのSNS投稿例ではありません。

羅針占術をThreadsで売り出すために、プロフィール、固定投稿、通常投稿、返信、投稿カレンダー、KPI、note誘導までを1つの流れとして設計します。

ここから先は、実際に30日運用へ落とすための有料部分です。

## 1. 結論

羅針占術のThreads運用は、次の5本柱で作る。

1. 毎朝の数秘オラクルで接触頻度を作る
2. 昼の投稿で「迷いの整理」という利用シーンを増やす
3. 夜の投稿で羅針占術の思想と差別化を伝える
4. 返信で悩みの言語化を拾い、投稿ネタへ戻す
5. noteで深い背景と運用ログを公開し、信頼の受け皿にする

羅針占術の強みは「占い結果そのもの」だけではない。

姓名判断、四柱推命、動物タイプ診断、ルノルマン、数秘オラクルを並べるだけなら、他の占いサービスと似て見える。Threadsで前面に出すべきなのは、機能数ではなく次の価値。

> 迷いを、判断できる形まで整理する。

この一文を中心に、すべての投稿を作る。

## 2. 調査から使うべき前提

### Xから持ってくる型

X公式のOrganic best practicesでは、ビジネス投稿の基本として次が示されている。

- 投稿文は簡潔にする
- ハッシュタグを避ける、または増やしすぎない
- 必要な場合は明確なCTAを入れる
- 全文大文字のような強すぎる表現を避ける
- 会話調にする
- 絵文字は感情を足す用途で使う
- メディアはタイムラインで目立つが、画像内の文字は重くしすぎない
- テストして、データから学ぶ

羅針占術へ翻訳すると、X型の投稿はこうなる。

- 1投稿1メッセージ
- 1投稿1悩み
- CTAは「無料で引く」か「保存する」のどちらか1つ
- ハッシュタグより本文の強さを優先
- リンクは毎回貼りすぎない
- 機能紹介より、読者の状態を先に書く
- 画像は説明資料ではなく、直感的に雰囲気が伝わるものを使う

### Threadsで変換する点

ThreadsはXよりも会話寄りに寄せる。

Meta公式のThreads教育情報では、返信がViewsの大きな割合を占め、2〜5回/週以上の投稿、会話を促す投稿、Threads専用のオリジナル投稿、テキスト付きの画像・動画・カルーセルが有効とされている。さらに、投稿にトピックを付けると表示が伸びやすい傾向も示されている。

Threadsでは「正解を言い切る投稿」よりも、「読者が自分の話をしたくなる投稿」が向いている。

羅針占術の場合、狙う返信は次のようなもの。

- 「これ今の自分です」
- 「恋愛でも見られますか」
- 「仕事の迷いにも使えますか」
- 「有料だとどこまで深くなりますか」
- 「今日のカード引きました」
- 「保存しました」

この返信を生む投稿は、単なる占い豆知識ではない。

読者の頭の中にある言葉にならない迷いを、短く代弁する投稿である。

## 3. 羅針占術のSNSポジション

羅針占術は、次のポジションで出す。

> 当たる/当たらないの消費型占いではなく、迷いの整理と次の判断を助けるAI占い。

避ける表現:

- 絶対当たる
- 未来を断言する
- これをやれば復縁できる
- 今すぐ課金しないと損
- AIがあなたの運命を決める

使う表現:

- 今の状況を整理する
- 本音と現実を分ける
- 次の一手を言葉にする
- 迷いの輪郭を見る
- 無料結果を深掘りする
- 占いを判断軸に変える

ルノルマンの説明は、タロットを下げない。

おすすめの説明:

> 羅針占術では、心の象徴を読むだけでなく、現実の状況整理と次の判断を重視しています。ルノルマンで今起きている流れを読み、数秘オラクルで打開点を見ます。

## 4. プロフィール設計

Threadsのプロフィールは、初見ユーザーが3秒で判断する場所。

プロフィールの目的は、フォローではなく「無料で1回試す理由」を作ること。

### 名前

### Bio案

```text

姓名判断・四柱推命・ルノルマン・数秘オラクル。
毎朝の数秘オラクルを投稿中。
無料鑑定はこちら👇
```

### リンク

第1リンク:

```text
https://rashin-senjutsu.onrender.com
```

noteやBOOTH導線を増やす場合は、プロフィールに複数リンクを入れられるThreads仕様を確認し、優先順位を次にする。

1. 羅針占術アプリ
2. note記事
3. BOOTHまたは有料説明ページ
4. X
5. Bluesky

## 6. 投稿の3レーン

羅針占術のThreads投稿は、3レーンで回す。

### レーンA: 毎朝の数秘オラクル

目的:

- 接触頻度を作る
- 保存・シェアの習慣を作る
- 無料体験への入口を作る

型:

```text
今日の数秘オラクル
カード: {カード名}

テーマ: {今日のテーマ}

今日は、{読者の状態を1文で言語化}。
焦って答えを出すより、{行動の方向性}。

今日の一手:
{具体的すぎない小さな行動}

無料で今日の1枚を引けます。
rashin-senjutsu.onrender.com
```

重要なのは、「命令」ではなく「整理」にすること。

悪い例:

```text
今日は絶対に連絡してください。
```

良い例:

```text
今日は、連絡する前に「何を確認したいのか」を1行だけ書いてみてください。
```

### レーンB: 昼の迷い整理投稿

目的:

- アプリの利用シーンを広げる
- 恋愛、仕事、人間関係、将来不安を自然に拾う
- 返信を生む

型:

```text
迷っているときほど、
「本当はどうしたいか」と
「今すぐ動けること」が混ざります。

羅針占術では、まずそこを分けます。

答えを急ぐ前に、
今の気持ちと現実を別々に見る。
それだけで、次の一手は少し見えやすくなります。
```

このレーンではURLを毎回貼らなくてよい。週2〜3回だけ、自然に無料鑑定へつなげる。

### レーンC: 夜の思想・差別化投稿

目的:

- 羅針占術の世界観を伝える
- 他のAI占いとの差別化をする
- 有料深掘りの必要性を育てる

型:

```text
占いは、未来を固定するものではなく、
今の自分を見直すための鏡だと思っています。

羅針占術では、
ルノルマンで現実の流れを見て、
数秘オラクルで打開点を見ます。

当てるだけで終わらせず、
次にどう動くかまで整理するための占いです。
```

## 7. 返信を増やす投稿の型

Threadsでは、返信される投稿が重要。

羅針占術で返信を作るには、質問を単純にする。

### 質問テンプレ

```text
今の迷いは、どちらに近いですか？

A: 気持ちは決まっているけど動けない
B: そもそも何を選びたいか分からない
```

```text
占いで見たいのはどっちですか？

A: 相手の気持ち
B: 自分が次にどう動くか
```

```text
今ほしい言葉はどちらですか？

A: 背中を押す言葉
B: 一度立ち止まる言葉
```

```text
迷っているとき、先に知りたいのはどっち？

A: 可能性
B: リスク
```

ポイントは、読者に長文回答を求めないこと。

「A/Bで答えられる」投稿は返信のハードルが低い。返信が増えたら、その返信を見て翌日の投稿テーマを作る。

## 8. 売り込みに見えないCTA

羅針占術のCTAは、強くしすぎない。

### 強すぎるCTA

```text
今すぐ有料鑑定を購入してください。
```

### 自然なCTA

```text
まずは無料で、今日の1枚を引いてみてください。
```

```text
結果をもう少し深く見たい人は、有料でそのまま深掘りできます。
```

```text
無料結果だけでも、今の迷いを整理する入口になります。
```

### 使い分け

- 朝: 無料で今日の1枚
- 昼: 返信、保存、共感
- 夜: 無料鑑定、必要な人だけ深掘り
- 固定投稿: 無料鑑定
- note: 羅針占術の考え方、裏側、運用ログ

## 11. note誘導設計

noteは、Threadsで言い切れない背景を置く場所にする。

羅針占術のnoteで書くべきテーマ:

- なぜ羅針占術を作ったのか
- AI占いで大事にしている倫理
- ルノルマンを使う理由
- 数秘オラクルを毎朝投稿する理由
- 無料鑑定と有料深掘りの違い
- 占い結果を行動に変える読み方
- Threads運用ログ
- ユーザーの悩みに直接触れすぎない一般化コラム

note記事の無料部分では、読者の悩みを言語化する。有料部分では、具体テンプレ、投稿例、運用表、失敗例、改善手順を出す。

### note記事の構成テンプレ

```text
タイトル
導入: 読者の悩みを代弁
結論: この記事で得られるもの
無料部分: 主要な考え方を1つ渡す
有料部分:
  1. 戦略
  2. 投稿型
  3. 実例
  4. 30日計画
  5. 計測表
  6. 失敗例
  7. 次の行動
最後: 羅針占術への自然な導線
```

## 12. 計測設計

Threadsの目的は「バズ」ではない。

羅針占術では、次の順番で見る。

1. Views
2. Replies
3. Reposts / Quotes
4. Profile visits
5. Link clicks
6. 無料鑑定開始
7. SNSシェア
8. 有料深掘り開始
9. 有料完了

### 投稿ごとの記録表

```text
日付:
時間:
レーン: 朝 / 昼 / 夜
投稿テーマ:
本文冒頭:
画像:
URLあり/なし:
Views:
Replies:
Reposts:
Quotes:
Profile visits:
Link clicks:
無料鑑定開始:
有料深掘り開始:
次に使える学び:
```

### 判断ルール

- Viewsだけ高く、返信がない投稿: 表現は強いが会話化していない
- 返信は多く、リンククリックが少ない投稿: 信頼形成向き
- リンククリックは多く、無料鑑定開始が少ない投稿: LPか導線に問題
- 無料鑑定開始は多く、有料深掘りが少ない投稿: 有料価値の説明不足
- 有料開始はあるが完了が少ない投稿: 決済・説明・不安解消の問題

## 13. やってはいけないこと

### 1. 毎回URLを貼る

すべての投稿を広告に見せると、返信が減る。URLは朝の習慣投稿、週2〜3回の無料鑑定導線、固定投稿に寄せる。

### 2. ハッシュタグを増やす

Threadsではブランドハッシュタグを増やすより、本文と会話を強くする。既存運用ではThreadsのハッシュタグは `#占い師のつぶやき` に絞る。

### 3. 未来を断言する

短期的にクリックは取れても、長期信頼を壊す。羅針占術は「判断軸を作る占い」として出す。

### 4. 有料を急がせる

無料で整理できる悩みもある、と言えるほうが信頼が残る。有料は「もっと深く見たいとき」に置く。

### 5. Xの文をそのままThreadsに貼る

Xは短く切る。Threadsは返信の余白を残す。同じテーマでも本文は変える。

### 週1回

- 返信から次週テーマを作る
- プロフィールと固定投稿を点検する

## 15. 羅針占術の勝ち筋

羅針占術は、派手な断言で売るアプリではない。

売り出す軸は、次の3つ。

1. 無料で触れる入口が多い
2. 結果をそのまま深掘りできる
3. 占いを「次の一手」に変える

Threadsでは、読者の迷いを毎日1つずつ言語化する。Xでは、その中から強い一文だけを切り出す。noteでは、なぜその言葉を選んだのか、どう運用しているのかを深く書く。

この3つを分けると、SNSはこう機能する。

- Threads: 共感と返信
- X: 短文の拡散と手動投稿
- note: 信頼と深掘り
- 羅針占術: 無料体験と有料深掘り

## 18. 内部運用メモ

- `docs/sns-runbook.md` はSNS投稿運用の正本。この資料は販売・コピー・戦略用であり、投稿実行手順の正本ではない。
- Xは現時点で自動投稿対象にしない。X下書きやX Web draftの扱いは既存runbookに従う。
- Threads本番投稿の完了判断は、`posted`、`existing_threads_post`、対象SNS側検証で行う。`due: []` や下書き生成だけを成功扱いしない。
- 有料CTAは、BOOTH/有料導線の本番確認状態に合わせて強さを調整する。
- 朝の数秘オラクル時刻は公開前に実運用へ合わせる。既存コード/Runbookの既定値は `08:00 Asia/Tokyo`。過去の固定投稿文には `7:30` 表記があるため、外部公開前に必ず統一する。
